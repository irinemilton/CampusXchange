# CampusXchange: Campus Circular Economy & Barter Platform

CampusXchange is a full-stack web application designed to facilitate a circular economy within university campuses. It allows students to barter academic resources (textbooks, electronics, lab equipment, etc.) using a virtual "Credit" system, promoting sustainability and resource sharing.

## 🚀 Overview

The platform functions as a marketplace where students can list items they no longer need and request items listed by others. Instead of traditional currency, the system uses **Campus Credits** to ensure a balanced exchange of value. Every transaction is recorded for audit purposes, and students gain starter credits upon registration.

- **Backend**: Python with [Flask 3.0.0](https://flask.palletsprojects.com/)

- **Authentication**: [Flask-Login](https://flask-login.readthedocs.io/)
- **Security**: [CSRF Protection](https://flask-wtf.readthedocs.io/en/latest/csrf/) (Flask-WTF) & Password Hashing ([Werkzeug](https://werkzeug.palletsprojects.com/))
- **Frontend**: HTML5, Vanilla CSS, and JavaScript (Jinja2 Templates)
- **Environment**: [Dotenv](https://pypi.org/project/python-dotenv/) for configuration management

## ✨ Core Features

### 1. User Management
- **Registration**: Secure sign-up limited to university `.edu` email addresses.
- **Login**: Secure authentication with failed-login attempt locking.
- **Profile**: Personal dashboard to manage listings, bios, and view transaction history.

### 2. Marketplace & Item Management
- **Browse & Search**: Filter items by category, condition, or keyword.
- **List Items**: Students can post academic gear with description, category, condition, and credit value.
- **Item Lifecycle**: Listings track availability from `Available` -> `Requested` -> `Exchanged`.

### 3. Barter Exchange System
- **Request Exchange**: Direct item-for-credits request system.
- **Double-Entry Ledger**: Every exchange involves an atomic transfer of credits from Receiver to Giver, recorded in a `CreditLedger` for auditing.
- **Atomic Transactions**: Uses database transactions to ensure credit balances and item statuses are updated systematically.

### 4. Gamification & Community
- **Leaderboard**: Displays top earners and most active traders.
- **Starter Credits**: New users are incentivized with 100 starter credits.

### 5. Administration
- **Admin Dashboard**: Specialized view for monitoring all students, items, and transactions.
- **Balance Adjustments**: Admins can manually adjust student credit balances if necessary.

## 📊 Database Architecture

The database consists of five primary tables:

1.  **`student`**: Stores student credentials, bio, and current `CreditBalance`.
2.  **`category`**: Defines types of academic resources (e.g., "Textbooks", "Electronics").
3.  **`item`**: Individual listings with details like `CreditValue`, `Condition`, and `Status`.
4.  **`exchange_transaction`**: Tracks the lifecycle of a barter request between two students.
5.  **`credit_ledger`**: A detailed audit trail of all credit inflows and outflows.

## ⚙️ Installation & Setup

1.  **Clone the Repository**:
    ```bash
    git clone https://github.com/your-repo/CampusXchange.git
    cd CampusXchange
    ```

2.  **Install Dependencies**:
    ```bash
    pip install -r requirements.txt
    ```

3.  **Configure Environment**:
    Create a `.env` file in the root directory:
    ```env
    SECRET_KEY=your_secret_key
    MYSQL_USER=your_username
    MYSQL_PASSWORD=your_password
    MYSQL_HOST=localhost
    MYSQL_DB=campus_barter
    ```

4.  **Initialize Database**:
    - Run the commands in `schema.sql` within your MySQL environment (Workbench/CLI).
    - Or run the application directly; it will initialize and seed the DB automatically on first run.

5.  **Run Application**:
    ```bash
    python app.py
    ```
    Access the platform at `http://127.0.0.1:5000/`.
